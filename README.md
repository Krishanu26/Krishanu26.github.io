# Krishanu Jana — Portfolio

A standalone, responsive portfolio built with HTML, CSS, and vanilla JavaScript. It has no install step and does not alter the existing application.

## Run locally

From PowerShell:

```powershell
cd C:\Moanbandhu\ORI_AI_Mental_Health_One_Click\portfolio
py -m http.server 4173
```

Open [http://localhost:4173](http://localhost:4173) in a browser. You can also open `index.html` directly.
